# 星域模式驗收清單

本清單供 CouCou 正式接入驗收。`verification.json` 是交付參考頁的檢查結果，不能代替以下正式版驗收。

## 視覺與空間

- [ ] Agent 使用光環與明亮光芯，透明四角沒有底色或方框。
- [ ] 同團隊自然靠近，團隊之間沒有卡片邊框。
- [ ] 成員存在深度與個別漂浮相位，軌道不完全同步。
- [ ] 名稱和團隊標籤清楚，Agent 排序變動不換色或亂跳位置。
- [ ] 320px 寬畫面沒有水平溢出，名稱、標籤和相機控制不相撞。
- [ ] 外框支持深淺主題；宇宙保持深色。

## 協作與真實資料

- [ ] 多人團隊所有成員都有核心關係線，且待機時持續可見。
- [ ] 單人團隊正常呈現，未捏造協作對象。
- [ ] 未任意添加跨團隊線，跨團隊訊息按真實 from/to 顯示。
- [ ] 點選 Agent 後直接關係加亮，狀態與角色來自真實資料。
- [ ] 傳送光流方向正確，動畫期間端點隨節點移動。
- [ ] 重複事件不重播，接收事件不覆寫真實完成時間。
- [ ] 事件過密時合併視覺效果，真實活動計數與紀錄仍保留。
- [ ] 正式版沒有固定示範路由或冒充即時的自動播放。
- [ ] 新增、刪除和封存團隊後，節點與連線正確更新。

## 動態與相機

- [ ] 無操作、無訊息時，背景星塵和柔光也會緩慢流動。
- [ ] 暫停後背景、節點、呼吸和裝飾亮點全部靜止；常駐線仍可見。
- [ ] 暫停不停止 AI 任務，資料仍更新，相機和選擇仍可操作。
- [ ] 減少動態停止持續動畫並用靜態傳送回饋。
- [ ] 系統要求減少動態時，初次開啟即遵守。
- [ ] 滑鼠拖曳、滾輪、單指拖曳、雙指縮放都能操作。
- [ ] 相機改變時，光圈、端點、曲線、名稱和命中區保持一致。
- [ ] 俯視、側視、全景有效，縮放範圍和百分比一致。
- [ ] 拖曳不會誤觸 Agent 選擇，鍵盤可以操作按鈕和節點。

## 效能與產品回歸

- [ ] 場景離開可視區或視窗隱藏後停止 frame，返回不重播過期效果。
- [ ] WebGL 初始化失敗和 context lost 均可使用 Canvas 後備。
- [ ] 後備仍支持慢移背景、常駐線、選擇和相機。
- [ ] 重複切換模式和頁面沒有重複事件訂閱或累積動畫。
- [ ] 卸載會釋放 observer、listener、RAF 和 GPU 資源。
- [ ] 在實際支援硬體測試效能，不只依據參考頁的 30fps 上限。
- [ ] 原 Office、中二模式、工作看板、Token、成本與任務流程正常。
- [ ] 完成專案要求的型別檢查、必要測試與 build，列出未完成項目。

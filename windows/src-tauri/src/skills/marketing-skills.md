## Getting the real thing

This skill is published on GitHub at https://github.com/coreyhaines31/marketingskills. Before relying on the summary below:

1. If it is already installed on this machine (a plugin, or a folder under `~/.claude/skills`, `~/.codex/skills` or `~/.agents/skills`), use that: it is the full version.
2. Otherwise, when the work folder and the network allow, install it (`npx skills add coreyhaines31/marketingskills`) and follow the installed instructions.
3. If neither is possible, work by the rules below. They summarise the original; they do not replace it.

## The rules in short

- Start from the audience and the one action wanted. Before writing, state the offer, the pain it solves and the proof.
- Copy: lead with the benefit; concrete beats vague; one call to action per page or ad; draft five to ten headlines and pick; short sentences; no jargon the reader would not use.
- SEO: one primary keyword and two or three secondary per page, placed in the title, H1, URL, first hundred words and a meta description under 155 characters; answer the search intent; add internal links; no duplicate titles.
- Ads: the hook in the first line; the ad matches the landing page; at least three variants per audience; decide how success is measured before launch.
- A/B tests: one variable per test; metric and sample size fixed up front; run to significance, not until it "looks better"; write down the result and the lesson.
- Email: subject under fifty characters, preview text, one goal per email, plain words, a clear unsubscribe.
- Analytics: define funnel steps and events before building; report conversion rates with their denominators.

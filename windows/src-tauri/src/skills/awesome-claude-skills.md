# Awesome Claude Skills（技能資源庫）

## Getting the real thing

This skill is published on GitHub at https://github.com/ComposioHQ/awesome-claude-skills. Before relying on the summary below:

1. If it is already installed on this machine (a plugin, or a folder under `~/.claude/skills`, `~/.codex/skills` or `~/.agents/skills`), use that: it is the full version.
2. Otherwise, when the work folder and the network allow, install it (browse the list and install the skill it points to) and follow the installed instructions.
3. If neither is possible, work by the rules below. They summarise the original; they do not replace it.

## The rules in short

- This is a catalogue, not a skill: a curated list of skills, plugins and tools by category (coding, documents, data, design, marketing, devops, …).
- When a task needs a skill nobody has: find the category in the list, open the candidate's repository, read its SKILL.md, check it is maintained and what its scripts run, then install it (`npx skills add owner/repo`, or copy the folder into the skills directory). Tell the user what was added and why.
- Prefer official skills (anthropics/skills) and widely used entries; read any script before running it.
- Add good finds to this app's Skill market so the whole team can pick them later.

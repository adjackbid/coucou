## Getting the real thing

This skill is published on GitHub at https://github.com/nextlevelbuilder/ui-ux-pro-max-skill. Before relying on the summary below:

1. If it is already installed on this machine (a plugin, or a folder under `~/.claude/skills`, `~/.codex/skills` or `~/.agents/skills`), use that: it is the full version.
2. Otherwise, when the work folder and the network allow, install it (`npx skills add nextlevelbuilder/ui-ux-pro-max-skill`) and follow the installed instructions.
3. If neither is possible, work by the rules below. They summarise the original; they do not replace it.

## The rules in short

- Pick one style direction first (minimal, editorial, glass, brutalist, playful…) and keep it across the whole product.
- Define tokens before components: palette (primary, accent, three to five neutrals, semantic success/warning/error), a heading and body type pair, a 4/8px spacing scale, radii and shadow levels. Everything references the tokens.
- Typography: at most two families; a clear scale by size and weight; 45 to 75 characters per line; body line height 1.4 to 1.6.
- Colour: text contrast at least 4.5:1; one accent for primary actions; neutrals carry the layout.
- Layout: one spacing scale, one alignment grid, related things grouped, generous whitespace, real breakpoints.
- UX: every control has hover, focus, disabled, loading, empty and error states; feedback within 100 ms; forms with labels and inline validation; everything reachable by keyboard.
- Follow the framework's own conventions (Tailwind, shadcn/ui, React, Vue, SwiftUI, Flutter…) rather than fighting them.
- With the full skill installed, run its search tool to get style, palette and font recommendations for the product; without it, apply the rules above.
